## 推荐执行顺序

1. **001** —— 单文件族改动，先补 `transition.ts` 的两个纯函数并跑通 `npm test`，再改 `index.tsx` 的三处渲染。
2. **002** —— 与 001 同一处端点一致性问题的另一半（阴影），改动在 `transition.ts` + `index.tsx:755`；两者共用一次"慢下拉不松手"的真机验收，不必各装一次包。
3. **003** —— 001 在长标题场景下的两个残留缺口（裁切语义 + 连接符越界）。会改 `getMorphSeparatorRect` 的签名，所以 001 的真机验收若发现的是短标题问题，不必等 003。
4. **004** —— 003 装机后暴露的长标题另一半：静态栏此时压根不画歌手，morph 层的歌手必须随行程淡掉，否则它会飞进歌名那一行、被零宽裁切框啃成"躲在空白块后面"。
