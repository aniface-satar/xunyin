# 寻音 1.2.0（原生版）发布说明

> 面向 GitHub Release 与酷安。正文两节可直接粘贴；末尾「发版记录」是内部用的。

## 一、本版看点

**把播放器整个重写了一遍**：从 React Native 换成 Kotlin + Compose（Media3 播放内核、QuickJS 音源运行时）。

- **启动更快、列表更稳**：release 包冷启动与旧版持平或略快，长列表滚动不再掉帧
- **17 套主题 + 封面取色**：换主题全局即时生效；播放页背景随封面取色（monet），可关
- **桌面歌词**：悬浮窗常驻，位置精确到小数、重启不漂移；译文与罗马音独立开关
- **五源搜索**：酷我 / 酷狗 / 企鹅 / 网易 / 咪咕，搜索结果、榜单、歌单、专辑、歌手统一在一处
- **本地曲库**：授权一个目录就能扫；读内嵌封面与歌词（ogg / flac / m4a 都支持）；文件挪了会自动找回
- **推荐与电台**：按语种配额取曲、可点「不喜欢」即时换掉；相似歌手与相似歌曲入口
- **无障碍**：播放页、主题页补齐读屏标签与 48dp 触控区

## 二、升级须知（请务必读）

1. **直接覆盖安装，歌单会自动带过来**——不需要导出导入。
   首次启动时，新版会读取旧版的应用私有数据，把试听列表、我的收藏、自建歌单一次性搬过来。
   旧版数据不会被删除。
2. **升级后不能回退**：Android 不允许降级安装。要回到旧版只能卸载重装，而卸载会清空数据，
   所以升级前建议先在旧版「设置 → 备份」里导出一份 `.lxmc` 放着。
3. **本版暂未包含：音乐下载、听歌识曲**。这两个功能仍在旧版里，依赖它们的用户请先不要升级，
   或升级前把已下载的文件处理好。后续版本会补上。
4. **首次启动会稍慢**（要读一次旧数据并建库），之后就正常了。

## 三、已知问题

- **真机验收未完整执行**：本次发布前没有条件做全量真机回归（190 条清单只做了构建与升级冒烟），
  取链、播放、分享卡等链路在真实网络与真实机型上的表现仍需观察。遇到问题请带机型与日志反馈。
- 推荐页在无网络时会显示一条正则解析错误文本（不影响播放，联网后自动恢复）。
- 部分设置项尚未迁移（旧版设置不会带过来，需要重新调一遍）。
