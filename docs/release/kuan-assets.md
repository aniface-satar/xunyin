**简介正文（约 120 字，可直接粘贴）**

> 寻音是一个把「本地曲库」和「在线音源」放在一起的播放器。原生重写版用 Kotlin + Compose 实现，
> 启动更快、滚动更稳；支持五源搜索、榜单、歌单导入、专辑与歌手详情、个性电台、桌面歌词与主题换肤。
> 不收集任何个人数据，没有广告和统计 SDK；歌单只存在你自己的设备上。
