本次更新幅度较大，推荐相关的功能是首次完整上线。

## 推荐

- 首次进入「推荐」会先问你几个听歌偏好，之后可随时在「设置 - 推荐偏好」修改
- 推荐歌单与新歌速递按你的口味挑选内容；长按歌单卡片或点歌曲行尾「不感兴趣」，同类内容会逐步少推
- 个性电台会记住你的听感：常听完的越推越多，连着被切的持续降权，还会熔断高风险曲目
- 播放队列里的电台曲目会显示入选原因（因为你常听 X / 来自歌单 / 来自榜单）
- 电台会按当前时段（清晨/白天/晚间/深夜）微调选歌，并从歌名学到「DJ版 / Live / 翻唱 / 伴奏」这类偏好词

## 修复

- 酷狗、酷我、咪咕的封面缺失问题（搜索列表、歌单详情、新歌速递、全屏播放页）
- 个性电台不再推荐「我喜欢 / 自建歌单」里已有的歌，也不会连续多首同一歌手
- 对其他歌单歌曲「稍后播放」后，点击下一首会优先播放你刚加入的歌
- 网络歌单、榜单、搜索结果中正在播放的歌曲条目现在高亮显示

## 优化

- 「我喜欢」与自建歌单的排序改为单列单选菜单，新增按添加时间、播放次数排序，并记住上次选择
- 电台/探索模式下的播放队列只展示你手动加入的歌曲，末尾显示搜索进度
