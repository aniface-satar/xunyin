<h1 align="center">寻音</h1>

<p align="center">基于 LX Music 移动版的界面重构版</p>

## 项目定位

寻音是基于 [LX Music 移动版](https://github.com/lyswhut/lx-music-mobile) 的界面重构版。原项目的核心内核保持未修改，播放、歌单数据、自定义源和备份恢复等基础能力继续沿用上游实现；重构集中在界面结构、视觉组织和操作流程，目标是让常用功能更容易被找到、更容易理解、也更容易上手。

LX Music 中导出的歌单可以直接导入到寻音。换句话说，从 LX Music 迁移到寻音时，歌单不需要逐首重建，备份中的列表数据可以在应用内完成导入。

## 与原版的主要不同

- **界面重构**：重新组织导航、列表和播放相关的界面，让高频操作更直观。
- **更低上手门槛**：原版 README 明确说明不以新手友好为目标；寻音则优先关注更清楚的入口、更易理解的层级和更顺手的常用路径。
- **歌单迁移友好**：支持导入 LX Music 导出的歌单备份，降低从原应用迁移的成本。

## 导入 LX Music 歌单

按照备份类型选择导入路径：

1. **完整列表备份**：进入「设置 → 备份与恢复 → 列表数据」，点击「导入列表」并选择 LX Music 导出的歌单备份文件。
2. **单个列表备份**：进入「我的列表」，点击任意列表名右侧的菜单按钮，在菜单中选择「导入」。
3. 若系统或应用直接打开了 `.lxmc` 等列表文件，寻音也会弹出确认提示，确认后即可导入。

导入前建议先在原应用或本应用中完成一次备份，避免同 ID 列表被覆盖时造成误操作。
